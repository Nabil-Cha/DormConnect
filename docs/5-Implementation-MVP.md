# Implementation of the MVP

To successfully implement our app, we prioritized the final features and consolidated the core functionalities into an MVP (Minimum Viable Product). This MVP includes the following key features:
- Creating activities in the database
- Creating communities in the database
- Displaying activities from the database
- Displaying communities from the database
- UI cleanup by removing buttons with unimplemented functionality, including:
    - QR code scanning
    - Search function on the Discover page
    - Push notifications

These steps were crucial to deliver the app on time with all necessary features for the upcoming testing phase. The app is now ready for the upcoming usability evaluation.
